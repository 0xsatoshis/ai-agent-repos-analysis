# AI Agent Repos Analysis

GitHub AI / Agent 仓库分类推荐清单，覆盖图片生成、语音识别、视频自动化、金融研究、Agent 编程、浏览器自动化等方向。

## 内容概览

本仓库对 GitHub 上主流 AI / Agent 相关开源项目进行系统化分类和推荐，帮助开发者快速定位适合自己场景的工具。

### 覆盖领域

| 分类 | 方向 |
|---|---|
| 图片 | ComfyUI、Stable Diffusion、Diffusers、超分修复、人脸识别 |
| 语音 | Whisper、TTS、中文语音生成、语音框架 |
| 视频 | FFmpeg、Remotion、短视频自动化、视频剪辑 |
| 自媒体采集与生产 | yt-dlp、Firecrawl、浏览器自动化 |
| 金融研究/回测 | OpenBB、Qlib、vn.py、TradingAgents |
| 设计系统/组件 | shadcn-ui、Ant Design、MUI、Tailwind CSS |
| Agent 编程工作流 | Codex、OpenHands、AutoGen、LangGraph |
| Agent 技能资产 | Skills 框架、提示词资产 |
| 浏览器/桌面自动化 | browser-use、Playwright、桌面 Agent |

### 排序标准

- 综合考虑工程可用性、生态成熟度、活跃度、许可证清晰度、落地成本和风险
- 优先推荐可直接用于生产/研究工作流的仓库
- 素材集、提示词集、方法论排在后面
